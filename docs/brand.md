# Trendix Brand System

## Brand essence
Trendix is a story-first marketplace designed to feel human, modular, and calm. The brand highlights trust, clarity, and automation without looking like a commodity grid.

## Color palette
| Token | Hex | Use |
| --- | --- | --- |
| Ink | #0E1013 | Primary text, navigation |
| Fog | #F4F3EF | Main background |
| Glow | #F7C870 | Accent gradients, highlights |
| Tide | #93B9F2 | Discovery panels |
| Moss | #B5D1A6 | Vendor panels |
| Plum | #7F6EF2 | Emphasis panels |
| Sand | #F2E7D9 | Warm background for hero |
| Rose | #F2B6B1 | Secondary accents |

## Typography
- **Headlines:** Space Grotesk (distinct, geometric warmth)
- **Body:** Manrope (neutral, legible, contemporary)

## Spacing system
- 8, 14, 22, 32, 48, 68 (mobile-first increments)

## Layout principles
- Vertical storytelling with asymmetrical panels.
- Modular sections instead of product grids.
- Progressive disclosure through collapsible cards and story layers.

## Motion
- Context-aware micro-animations (panel expansions, filter reveals).
- No auto-playing carousels or flashing banners.
