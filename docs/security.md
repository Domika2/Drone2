# Trendix Security & Compliance

## Authentication
- JWT-based sessions for API calls.
- OAuth providers for customer onboarding.
- Role-based access control (customer, vendor, dropshipper).

## Data protection
- Encrypt PII at rest and in transit.
- Tokenized payment data handled by payment providers.
- Audit logs for role and payout changes.

## GDPR readiness
- Data export endpoints per user.
- Right-to-delete workflow with soft delete + anonymization.
- Consent tracking for marketing communications.
